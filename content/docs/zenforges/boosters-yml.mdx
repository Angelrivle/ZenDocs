# Potenciadores (boosters.yml)

---

Define los ítems consumibles para acelerar forjados o ganar más experiencia.

```yaml
time-boosters:
  polvo_fuego:
    material: "eco:ecoitems:polvo_fuego" # O ítem vanilla / itemedit
    type: FIXED                         # FIXED (segundos fijos) o PERCENTAGE (% del total)
    amount: 600                         # Reduce 600 segundos (10 minutos)
    display-name: "&cPolvo de Fuego"
    sound: "BLOCK_FIRE_AMBIENT"

  reloj_arena:
    material: "itemedit:reloj_arena"
    type: PERCENTAGE
    amount: 20                          # Reduce el 20% del tiempo total
    display-name: "&eReloj de Arena Ancestral"
    sound: "BLOCK_BEACON_ACTIVATE"

xp-boosters:
  pocion_herrero:
    material: "eco:ecoitems:pocion_herrero"
    multiplier: 1.5                     # 1.5 = +50% extra de XP de herrería
    duration: 1800                      # 30 minutos (en segundos)
    display-name: "&dElíxir del Herrero Ancestral"
```
