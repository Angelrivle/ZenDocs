# ZenDuels

Bienvenido a la guía exhaustiva y técnica de configuración de **ZenDuels**. Este documento reúne toda la información necesaria para configurar, administrar y personalizar cada aspecto del plugin: almacenamiento de datos, mundos virtuales, sistema de ELO, jaulas físicas y animadas, inteligencia artificial de bots FakePlayer, grabaciones y repeticiones (Replays), sistemas de sonido, scoreboards, kits, arenas, menús interactivos, mensajes y permisos.
