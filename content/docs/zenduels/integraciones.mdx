# Integraciones y Dependencias

---

- **FastAsyncWorldEdit (FAWE)** *(Obligatorio)*: Utilizado para la captura, copiado, clonación instantánea y regeneración masiva de arenas en hilos asíncronos.
- **PlaceholderAPI (PAPI)** *(Opcional)*: Permite exponer estadísticas y datos de ZenDuels en otros plugins (Scoreboards externos, TAB, Chat, etc.).
- **Vault** *(Opcional)*: Permite recompensas monetarias o cobro de inscripciones para torneos.
- **Citizens** *(Opcional)*: Proveedor alternativo de NPCs si no se utiliza el motor nativo `NATIVE`.
- **ViaVersion** *(Opcional)*: Compatibilidad multiversión entre clientes 1.8 - 1.21.
