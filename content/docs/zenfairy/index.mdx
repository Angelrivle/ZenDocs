# ZenFairy

**ZenFairy** es un plugin avanzado para servidores Minecraft (Paper / Purpur 1.21+) enfocado en la creación y recolección de **Almas Personalizables (Souls)** con soporte nativo para Adventure API, formato MiniMessage, menús interactivos sin recarga, persistencia asíncrona de alto rendimiento con pool de conexiones HikariCP, detección espacial de proximidad con radar inmersivo y entidades de visualización (*Display Entities*).
