# Formato de Texto y MiniMessage

---

ZenFairy soporta la sintaxis moderna **MiniMessage** de la Adventure API de Paper, así como compatibilidad retroactiva con códigos clásicos con `&` y colores hexadecimales:

- **Gradientes:** `<gradient:#ff5555:#ffaa00>Texto con degradado</gradient>`
- **Efecto Arcoíris:** `<rainbow>Texto multicolor</rainbow>`
- **Estilos:** `<bold>`, `<italic>`, `<underlined>`, `<strikethrough>`, `<obfuscated>`, `<reset>`
- **Colores Básicos:** `<red>`, `<green>`, `<blue>`, `<yellow>`, `<aqua>`, `<gold>`, `<light_purple>`, etc.
- **Hexadecimal:** `<#ff70a6>` o `&#ff70a6`
- **Legacy:** `&a`, `&b`, `&c`, `&l`, etc.
