# Requisitos del Sistema

---

- **Servidor:** Paper / Purpur 1.21 o superior.
- **Java:** Java 17 o Java 21+.
- **Dependencias Obligatorias:**
  - *Ninguna* (HikariCP y Triumph-GUI vienen sombreados e integrados en el núcleo del plugin).
- **Dependencias Opcionales:**
  - **PlaceholderAPI**: Para el uso de variables en scoreboards, menús y chat.
  - **AuraSkills**: Para recompensar estadísticas pasivas de rol (`[AURA-STAT]`).
