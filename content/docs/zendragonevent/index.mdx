# ZenDragonEvent

Bienvenido a la documentación oficial y exhaustiva de **ZenDragonEvent**, un plugin premium de eventos de invocación de dragones estilo MMORPG diseñado específicamente para **Paper 1.21.4 (Java 21)** con soporte nativo de la **Adventure API**, **MiniMessage**, compatibilidad dual con **TAB**, y concurrencia optimizada de alto rendimiento.
