# Integraciones y Dependencias

---

ZenCosmetics está compilado y optimizado para servidores **Paper / Purpur 1.21.x** (Java 21).

### Dependencias Obligatorias:
- **Vault**: Sistema base para la economía tradicional del servidor (monedas/balance).

### Dependencias Opcionales (Soft-Dependencies):
- **PlaceholderAPI**: Para mostrar nombres coloreados, prefijos de chat y cosméticos activos en Scoreboard, TAB o Chat.
- **EcoBits**: Permite utilizar monedas personalizadas alternativas (cristales, gemas, etc.).
- **ZenProfiles**: Permite sincronización e intercambio dinámico de perfiles y cosméticos por perfil de jugador.
