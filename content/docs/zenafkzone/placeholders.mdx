# Placeholders (PAPI)

---

ZenAfkZone registra la expansión `%zenafkzone_%`:

| Placeholder | Descripción | Ejemplo de Salida |
| :--- | :--- | :--- |
| `%zenafkzone_zone%` | Nombre interno de la zona actual del jugador | `vip` (o `Ninguna`) |
| `%zenafkzone_zone_display%` | Nombre formateado/display de la zona actual | `Zona VIP AFK` |
| `%zenafkzone_time_left%` | Tiempo restante para el siguiente ciclo | `04:32` |
| `%zenafkzone_progress%` | Porcentaje de progreso numérico | `65` |
| `%zenafkzone_top_time_<pos>_name%` | Nombre del jugador en el ranking Top AFK | `Player123` |
| `%zenafkzone_top_time_<pos>_value%` | Tiempo total acumulado del jugador en el Top AFK | `12h 45m 10s` |
