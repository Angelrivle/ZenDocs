# Permisos

---

| Permiso | Descripción | Por Defecto |
| :--- | :--- | :--- |
| `zenafkzone.help` | Permite usar `/zenafkzone help` | Todos |
| `zenafkzone.gui` | Permite abrir el menú `/zenafkzone gui` o `/afk` | Todos |
| `zenafkzone.tp` | Permite usar `/zenafkzone tp <zona>` | Operadores (OP) |
| `zenafkzone.wand` | Permite recibir la varita de selección `/zenafkzone wand` | Operadores (OP) |
| `zenafkzone.create` | Permite crear zonas `/zenafkzone create <zona>` | Operadores (OP) |
| `zenafkzone.delete` | Permite borrar zonas `/zenafkzone delete <zona>` | Operadores (OP) |
| `zenafkzone.redefine` | Permite redefinir las coordenadas de una zona | Operadores (OP) |
| `zenafkzone.list` | Permite listar las zonas registradas | Operadores (OP) |
| `zenafkzone.reload` | Permite recargar las configuraciones `/zenafkzone reload` | Operadores (OP) |
| `zenafkzone.bypass.iplimit` | Ignora el límite de cuentas simultáneas por IP | Operadores (OP) |
| `zenafkzone.timeboost.<grupo>` | Aplica reducción porcentual en el tiempo de recompensa | Ninguno |
| `zenafkzone.multiplier.<grupo>`| Aplica multiplicadores de ítems y roll amount | Ninguno |
