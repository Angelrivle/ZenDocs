# ZenAfkZone

ZenAfkZone es un plugin de alto rendimiento diseñado para **Paper 1.21+** que gestiona zonas de descanso AFK con recompensas periódicas, efectos ambientales, integración con **Adventure API / MiniMessage**, base de datos optimizada en SQLite y hologramas nativos con TextDisplay (sin requerir plugins externos).
