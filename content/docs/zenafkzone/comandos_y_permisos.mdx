# Comandos y Permisos

---

| Comando | Argumentos | Descripción |
| :--- | :--- | :--- |
| `/afk` o `/zenafkzone` | `gui` | Abre la interfaz gráfica interactiva con las zonas disponibles. |
| `/zenafkzone` | `wand` | Entrega la varita para definir esquinas de cuboides. |
| `/zenafkzone` | `create <nombre>` | Crea una nueva zona utilizando la selección activa de la wand. |
| `/zenafkzone` | `delete <nombre>` | Elimina una zona y su archivo YAML. |
| `/zenafkzone` | `redefine <nombre>` | Actualiza las coordenadas de una zona con la selección activa. |
| `/zenafkzone` | `tp <nombre>` | Teletransporta de manera asíncrona al spawn de la zona. |
| `/zenafkzone` | `list` | Lista las zonas activas y el número de jugadores en cada una. |
| `/zenafkzone` | `reload` | Recarga todos los archivos YAML de configuración y zonas. |
