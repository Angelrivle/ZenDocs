# Prestigios (prestige.yml)

---

Define los rangos de prestigio para jugadores que ya completaron todos los rangos de `ranks.yml`.

```yaml
default-prestige: 0

prestiges:
  1:
    displayname: "&aPrestigio I"
    symbol: "&a[Prestigio I]"
    reset-ranks: true # Reinicia al jugador al default-rank al subir prestigio
    requeriments:
      - "[COST-VAULT] 100000"
      - "[PLAYTIME] 1440"
    command:
      - "[CONSOLE]lp user %player% meta setprefix &a[P-I] "
      - "[CONSOLE]give %player% netherite_ingot 3"
      - "[CONSOLE]broadcast &e%player% ha alcanzado el &aPrestigio I&e!"
  2:
    displayname: "&ePrestigio II"
    symbol: "&e[Prestigio II]"
    reset-ranks: true
    requeriments:
      - "[COST-VAULT] 250000"
    command:
      - "[CONSOLE]give %player% netherite_block 1"
```
