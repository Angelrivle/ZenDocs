# Estructura de Archivos

---

Al instalarse, ZenRankups genera en la carpeta `plugins/ZenRankups/` los siguientes archivos:
```
plugins/ZenRankups/
├── config.yml       # Módulos globales, base de datos, mensajes y efectos visuales
├── ranks.yml        # Definición de rangos, requisitos, recompensas y caminos
├── prestige.yml     # Niveles de prestigio, costos y recompensas
├── menu.yml         # Menú GUI inteligente (/ranks) y formato de requisitos
└── webhooks.yml     # Integración de embeds y alertas a canales de Discord
```
