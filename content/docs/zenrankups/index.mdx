# ZenRankups

ZenRankups es un plugin de progresión de rangos y prestigios de alto rendimiento diseñado específicamente para servidores PaperMC (1.20+) con integración completa y nativa de **Paper Adventure API**, MiniMessage, persistencia en SQLite/MySQL con HikariCP y Write-Behind Caching, y un sistema extensible de requisitos y webhooks de Discord.
