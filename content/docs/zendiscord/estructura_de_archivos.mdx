# Estructura de Archivos

---

```text
plugins/ZenDiscord/
├── config.yml            # Configuración principal, bot, módulos y vincualción
├── embeds.yml            # Formato y estilo visual de todos los embeds de avisos
├── moderation.yml        # Auditoría de comandos vigilados y logs por webhook
├── tops.yml              # Configuración de clasificaciones e imágenes de tops
├── leaderboard.html      # Plantilla HTML/CSS para renderizar leaderboards a PNG
└── zendiscord.db         # Base de datos SQLite (Cuentas vinculadas y recompensas)
```
