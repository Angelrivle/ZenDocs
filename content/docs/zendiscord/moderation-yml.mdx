# Auditoría de Comandos (moderation.yml)

---

Envía un log detallado por Webhook cada vez que alguien usa un comando sensible:
```yaml
webhook-url: "https://discord.com/api/webhooks/..."
monitored-commands:
  - "/ban"
  - "/tempban"
  - "/kick"
  - "/mute"
  - "/op"
  - "/gamemode"
```
