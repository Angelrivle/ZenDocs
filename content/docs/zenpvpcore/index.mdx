# ZenPvPCore

**ZenPvPCore** es un núcleo integral de PvP competitivo desarrollado para **PaperMC 1.21.x** en **Java 21**, diseñado para alto rendimiento, compatibilidad nativa con la API **Adventure (MiniMessage)** y soporte para bases de datos **SQLite** y **MySQL** mediante HikariCP.
