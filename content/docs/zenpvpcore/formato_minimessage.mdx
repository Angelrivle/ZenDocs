# Formato de Texto y MiniMessage

---

ZenPvPCore utiliza la librería **Kyori Adventure MiniMessage** de forma nativa. Esto permite el uso de etiquetas modernas sin códigos arcaicos de `&`:

- **Colores Básicos**: `<red>`, `<green>`, `<blue>`, `<yellow>`, `<gold>`, `<gray>`, `<dark_gray>`, `<white>`, `<aqua>`, `<dark_purple>`, etc.
- **Colores Hexadecimales**: `<color:#ff3333>`, `<#1c7bff>`, `<color:#cd7f32>`
- **Gradientes y Efectos**:
  - `<gradient:#ff0000:#0000ff>Texto con degradado</gradient>`
  - `<rainbow>Texto arcoíris</rainbow>`
- **Estilos**:
  - `<b>` o `<bold>`: **Negrita**
  - `<i>` o `<italic>`: *Cursiva*
  - `<u>` o `<underlined>`: `<u>`Subrayado`</u>`
  - `<st>` o `<strikethrough>`: `<s>`Tachado`</s>`
  - `<obf>` o `<obfuscated>`: Texto aleatorio
  - `<!italic>`: Desactiva la cursiva forzada por defecto en nombres de ítems y títulos de inventario.
