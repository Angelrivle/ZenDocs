# Sistema ELO (elo_system.yml)

---

### 4.1 Configuración Base y Algoritmo Dinámico (K-Factor / MMR)

```yaml
enabled: true                    # Activar o desactivar el sistema ELO
starting_elo: 1000               # ELO inicial asignado a un jugador nuevo
base_kill_elo: 15                # ELO base otorgado por una kill estándar
base_death_elo: 10               # ELO base restado por morir
base_assist_elo: 5               # ELO por asistencia (si aplica)

# Algoritmo Dinámico de Matchmaking (K-Factor / MMR)
# Ajusta la ganancia y pérdida según la diferencia de habilidad entre la víctima y el asesino
dynamic_k_factor:
    enabled: true
  k_factor: 32                   # Factor de volatilidad (estándar de ajedrez / juegos competitivos)
  min_gain: 5                    # Mínimo de ELO que se puede ganar (evita 0 ELO)
  max_gain: 45                   # Máximo de ELO que se puede ganar (al matar a alguien de mucho más ELO)
  min_loss: 5                    # Mínimo de ELO que se puede perder
  max_loss: 35                   # Máximo de ELO que se puede perder

# Multiplicadores de ganancia
global_booster: 1.0              # Multiplicador global para todo el servidor
clan_booster_multiplier: 1.2     # Multiplicador adicional si el jugador pertenece a un Clan (UltimateClans)

# Webhook de Discord para anunciar subidas de rango
webhook_url: "https://discord.com/api/webhooks/YOUR_WEBHOOK_URL"
```

### 4.2 Boosters, Clanes y Webhook

- Si un jugador tiene clan en **UltimateClans**, su ganancia de ELO se multiplicará por `clan_booster_multiplier`.
- Al subir de rango, el plugin enviará automáticamente un Embed estilizado a la URL de `webhook_url` con el avatar del jugador, rango alcanzado y ELO actual.

### 4.3 Penalización por Inactividad

```yaml
penalty:
    enabled: true
  days_inactive: 7               # Días sin conectarse requeridos para recibir penalización
  elo_loss: 15                   # ELO restado periódicamente por inactividad
```
