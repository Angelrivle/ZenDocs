# ZenChatGames

**Plugin de juegos de chat de alto rendimiento para Paper 1.21+**  
*Manejo 100% nativo con Kyori Adventure (MiniMessage), base de datos híbrida (SQLite/MySQL) con pool de conexiones HikariCP y soporte para PlaceholderAPI.*
