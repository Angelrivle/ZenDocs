# `set_variable`

* **Categoría:** `Estado del Ítem`  
* **Identificador / Alias:** `SET_VARIABLE`

---

Establece el valor de una variable del ítem.
```yaml
effects:
  - type: SET_VARIABLE
    variable: combo
    value: 0
```
