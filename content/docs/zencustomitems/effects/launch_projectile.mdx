# `launch_projectile`

* **Categoría:** `Entidades & Proyectiles`  
* **Identificador / Alias:** `LAUNCH_PROJECTILE`

---

Dispara un proyectil (`SNOWBALL`, `FIREBALL`) desde el jugador.
```yaml
effects:
  - type: LAUNCH_PROJECTILE
    type: FIREBALL
    speed: 1.8
```
