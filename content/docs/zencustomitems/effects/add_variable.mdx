# `add_variable`

* **Categoría:** `Estado del Ítem`  
* **Identificador / Alias:** `ADD_VARIABLE`

---

Suma una cantidad numérica a una variable persistente del ítem.
```yaml
effects:
  - type: ADD_VARIABLE
    variable: combo
    amount: 1
```
