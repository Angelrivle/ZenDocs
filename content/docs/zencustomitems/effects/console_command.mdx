# `console_command`

* **Categoría:** `Comandos`  
* **Identificador / Alias:** `CONSOLE_COMMAND`

---

Ejecuta un comando con permisos de la consola de Minecraft.
```yaml
effects:
  - type: CONSOLE_COMMAND
    command: "eco give %player% 100"
```
