# `cancel_event`

* **Categoría:** `Estado del Ítem`  
* **Identificador / Alias:** `CANCEL_EVENT`

---

Cancela el evento nativo de Bukkit que originó el trigger (previene el daño, la rotura del bloque o el clic).
```yaml
effects:
  - type: CANCEL_EVENT
```
