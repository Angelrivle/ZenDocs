# `true_damage`

* **Categoría:** `Nuevos Efectos Extendidos de Combate y Estrategia`  
* **Identificador / Alias:** `TRUE_DAMAGE`

---

Inflige daño puro directo que ignora la reducción de armadura, encantamientos de protección y escudos.
```yaml
effects:
  - type: TRUE_DAMAGE
    amount: 6.0
```
