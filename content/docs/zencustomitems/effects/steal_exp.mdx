# `steal_exp`

* **Categoría:** `Nuevos Efectos de Entidad, Auras y Utilidad`  
* **Identificador / Alias:** `STEAL_EXP / DEPOSIT_EXP`

---

Permite absorber o almacenar niveles/experiencia en el ítem.
```yaml
effects:
  - type: STEAL_EXP
    amount: 25
```
