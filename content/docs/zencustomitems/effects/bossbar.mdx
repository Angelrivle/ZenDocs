# `bossbar`

* **Categoría:** `Mensajes & UI`  
* **Identificador / Alias:** `BOSSBAR`

---

Muestra una barra de jefe personalizada en la parte superior.
```yaml

  - type: BOSSBAR
    title: "<gold>Tiempo restante"
    progress: 1.0
    color: PURPLE
```
