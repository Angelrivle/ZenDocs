# `set_glide`

* **Categoría:** `Nuevos Efectos de Movilidad y Parkour`  
* **Identificador / Alias:** `SET_GLIDE`

---

Activa o desactiva el planeo de élitros en el jugador.
```yaml
effects:
  - type: SET_GLIDE
    glide: true
```
