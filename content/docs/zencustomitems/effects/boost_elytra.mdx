# `boost_elytra`

* **Categoría:** `Nuevos Efectos de Movilidad y Parkour`  
* **Identificador / Alias:** `BOOST_ELYTRA`

---

Otorga un cohete de propulsión instantáneo si el jugador está usando élitros en vuelo.
```yaml
effects:
  - type: BOOST_ELYTRA
    multiplier: 1.8
```
