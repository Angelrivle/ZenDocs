# `particle`

* **Categoría:** `Efectos Visuales & Rayos Cinemáticos`  
* **Identificador / Alias:** `PARTICLE`

---

Genera una nube estática de partículas.
```yaml
effects:
  - type: PARTICLE
    particle: CRIT
    count: 25
    speed: 0.2
```
