# `execute`

* **Categoría:** `Nuevos Efectos Extendidos de Combate y Estrategia`  
* **Identificador / Alias:** `EXECUTE`

---

Elimina instantáneamente al objetivo si su vida se encuentra por debajo del porcentaje configurado.
```yaml
effects:
  - type: EXECUTE
    threshold: 15.0
```
