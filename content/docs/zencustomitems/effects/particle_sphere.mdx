# `particle_sphere`

* **Categoría:** `Efectos Visuales & Rayos Cinemáticos`  
* **Identificador / Alias:** `PARTICLE_SPHERE`

---

Dibuja una esfera tridimensional de partículas.
```yaml
effects:
  - type: PARTICLE_SPHERE
    particle: SOUL_FIRE_FLAME
    radius: 2.5
```
