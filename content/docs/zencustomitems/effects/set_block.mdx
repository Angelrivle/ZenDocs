# `set_block`

* **Categoría:** `Mundo & Bloques`  
* **Identificador / Alias:** `SET_BLOCK / PLACE_BLOCK`

---

Cambia el bloque en la posición por otro material.
```yaml
effects:
  - type: SET_BLOCK
    material: COBWEB
```
