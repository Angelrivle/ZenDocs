# `spawn_particle_ring`

* **Categoría:** `Nuevos Efectos de Entidad, Auras y Utilidad`  
* **Identificador / Alias:** `SPAWN_PARTICLE_RING`

---

Genera un anillo circular de partículas decorativas o de advertencia.
```yaml
effects:
  - type: SPAWN_PARTICLE_RING
    radius: 3.5
    count: 32
```
