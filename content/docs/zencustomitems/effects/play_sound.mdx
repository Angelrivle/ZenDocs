# `play_sound`

* **Categoría:** `Sonidos`  
* **Identificador / Alias:** `PLAY_SOUND / SOUND`

---

Reproduce un sonido de Minecraft con volumen y tono ajustables.
```yaml
effects:
  - type: PLAY_SOUND
    sound: ENTITY_WITHER_SPAWN
    volume: 1.0
    pitch: 1.2
```
