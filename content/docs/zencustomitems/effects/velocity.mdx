# `velocity`

* **Categoría:** `Movimiento & Física`  
* **Identificador / Alias:** `VELOCITY`

---

Aplica un vector de aceleración en los ejes X, Y, Z.
```yaml
effects:
  - type: VELOCITY
    x: 0.0
    y: 1.0 # Impulso vertical alto
    z: 0.0
```
