# `poison_cloud`

* **Categoría:** `Nuevos Efectos Extendidos de Combate y Estrategia`  
* **Identificador / Alias:** `POISON_CLOUD`

---

Invoca una nube tóxica que envenena a todas las criaturas enemigas en el radio.
```yaml
effects:
  - type: POISON_CLOUD
    radius: 4.0
    duration: 120
```
