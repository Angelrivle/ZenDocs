# `set_durability`

* **Categoría:** `Estado del Ítem`  
* **Identificador / Alias:** `SET_DURABILITY`

---

Modifica directamente la durabilidad actual del ítem.
```yaml
effects:
  - type: SET_DURABILITY
    durability: 500
```
