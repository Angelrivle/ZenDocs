# `message`

* **Categoría:** `Mensajes & UI`  
* **Identificador / Alias:** `MESSAGE`

---

Envía un mensaje formateado al chat con soporte de MiniMessage y variables.
```yaml
effects:
  - type: MESSAGE
    message: "<gradient:#ffaa00:#ffff55><bold>¡Poder Activado!</bold></gradient>"
```
