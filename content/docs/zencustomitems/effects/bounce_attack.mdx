# `bounce_attack`

* **Categoría:** `Nuevos Efectos Extendidos de Combate y Estrategia`  
* **Identificador / Alias:** `BOUNCE_ATTACK`

---

El ataque rebota sucesivamente entre múltiples enemigos cercanos.
```yaml
effects:
  - type: BOUNCE_ATTACK
    bounces: 4
    radius: 6.0
    damage: 5.0
```
