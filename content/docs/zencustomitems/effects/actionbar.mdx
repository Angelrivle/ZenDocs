# `actionbar`

* **Categoría:** `Mensajes & UI`  
* **Identificador / Alias:** `ACTIONBAR`

---

Muestra un texto flotante en la barra de acción sobre la hotbar.
```yaml
effects:
  - type: ACTIONBAR
    message: "<yellow>⚔ Furia activada: +25% Daño"
```
