# `lightning`

* **Categoría:** `Mundo & Bloques`  
* **Identificador / Alias:** `LIGHTNING`

---

Invoca un relámpago en la ubicación del objetivo o bloque.
```yaml
effects:
  - type: LIGHTNING
    target: TARGET
    strike: true # Si es true, inflige daño de rayo
```
