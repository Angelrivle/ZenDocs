# `meteor_shower`

* **Categoría:** `Nuevos Efectos de Entidad, Auras y Utilidad`  
* **Identificador / Alias:** `METEOR_SHOWER`

---

Bombardea el área con una lluvia de pequeñas bolas de fuego.
```yaml
effects:
  - type: METEOR_SHOWER
    count: 6
```
