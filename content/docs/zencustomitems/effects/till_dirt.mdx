# `till_dirt`

* **Categoría:** `Nuevos Efectos de Minería, Agricultura y Entorno`  
* **Identificador / Alias:** `TILL_DIRT / PATH_DIRT`

---

Crea arados o senderos de tierra en radio de forma instantánea.
```yaml
effects:
  - type: TILL_DIRT
    radius: 3
```
