# `double_jump`

* **Categoría:** `Nuevos Efectos de Movilidad y Parkour`  
* **Identificador / Alias:** `DOUBLE_JUMP`

---

Otorga un impulso en el aire estilo doble salto con partículas de nube.
```yaml
effects:
  - type: DOUBLE_JUMP
    power: 0.85
```
