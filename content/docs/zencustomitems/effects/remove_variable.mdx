# `remove_variable`

* **Categoría:** `Estado del Ítem`  
* **Identificador / Alias:** `REMOVE_VARIABLE`

---

Elimina una variable almacenada.
```yaml
effects:
  - type: REMOVE_VARIABLE
    variable: combo
```
