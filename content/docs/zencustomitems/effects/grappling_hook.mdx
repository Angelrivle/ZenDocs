# `grappling_hook`

* **Categoría:** `Nuevos Efectos de Movilidad y Parkour`  
* **Identificador / Alias:** `GRAPPLING_HOOK`

---

Propulsa al jugador a toda velocidad hacia la ubicación o bloque seleccionado.
```yaml
effects:
  - type: GRAPPLING_HOOK
    speed: 2.0
```
