# `arrow_hit`

* **Categoría:** `Proyectiles`  
* **Identificador / Alias:** `ARROW_HIT`

---

Se dispara específicamente cuando una flecha disparada impacta en un objetivo.
```yaml
triggers:
  - id: lightning_arrow
    type: ARROW_HIT
    effects:
      - type: LIGHTNING
        target: TARGET
```
