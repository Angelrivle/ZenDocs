# Requisitos del Sistema

---

- **Servidor**: Paper, Purpur o forks derivados compatibles con **Minecraft 1.21.x** en adelante.
- **Java**: Java 21 o superior.
- **Dependencias Obligatorias**: Ninguna (todo el motor de efectos, interfaz y NBT con PDC es nativo).
- **Dependencias Opcionales**: Vault (para economías basadas en dinero de servidor en la tienda misteriosa).
