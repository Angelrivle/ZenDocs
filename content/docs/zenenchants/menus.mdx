# Configuración de Menús (menus/)

---

El menú abierto con `/enchants` o `/ze` incluye:
1. **Filtro de Objeto / Búsqueda (Slot 4)**:
   - **Click Izquierdo**: Abre el chat para escribir un término o nombre a buscar.
   - **Colocar un Objeto (Drag & Drop)**: Coloca una espada, pico, pechera o cualquier ítem para filtrar al instante todos los encantamientos aplicables a él. Si el objeto no tiene encantamientos disponibles, muestra una barrera de `No Data`.
2. **Identificador Técnico Visible**:
   - En la lista de encantamientos, se muestra el ID técnico en gris oscuro justo debajo del nombre (ej. `aerial_dominance`).
3. **Limpiar Filtros (Slot 45)**:
   - Restablece cualquier filtro activo y devuelve el objeto colocado a tu inventario.
4. **Paginación y Salida**:
   - Botones para avanzar o retroceder de página con total fluidez.
5. **Obtención para Administradores**:
   - Los jugadores con `zenenchants.admin` pueden hacer **clic derecho** sobre cualquier libro del menú para obtenerlo inmediatamente.
