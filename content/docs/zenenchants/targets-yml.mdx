# Categorías y Objetivos (targets.yml)

---

El archivo `targets.yml` categoriza sobre qué objetos se pueden aplicar los encantamientos y permite desbloquear objetos adicionales en la mesa de encantamientos:

```yaml
# Ítems que normalmente no se encantan en la mesa pero aquí se permiten
extra-enchantable-items:
 - "*elytra"
 - "*shield"
 - "*flint_and_steel"
 - "*shears"
 - "*carrot_on_a_stick"
 - "*player_head"

# Definición de categorías
targets:
 - id: pickaxe
    display-name: "Picos"
    slot: mainhand
    items:
 - "#items_pickaxes"

 - id: sword
    display-name: "Espadas"
    slot: mainhand
    items:
 - "#items_swords"

 - id: helmet
    display-name: "Cascos"
    slot: helmet
    items:
 - "#items_head_armor"

 - id: armor
    display-name: "Armaduras"
    slot: armor
    items:
 - "#items_head_armor"
 - "#items_chest_armor"
 - "#items_leg_armor"
 - "#items_foot_armor"
```

### Características de Targets:
- **Tags de Grupo**: Soporta `#items_pickaxes`, `#items_swords`, `#items_axes`, `#items_head_armor`, etc.
- **Patrones y Comodines**: Soporta `*elytra`, `*shield`, `*bow`, o `*` para todos.
- **Ranuras de Activación (`slot`)**: `mainhand`, `offhand`, `hands`, `armor`, `helmet`, `chestplate`, `leggings`, `boots`, `any`.
