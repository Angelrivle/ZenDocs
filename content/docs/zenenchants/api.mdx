# API para Desarrolladores

---

Este documento explica cómo integrar **ZenEnchants** en plugins externos de ítems (como plugins de ítems custom, MMOItems, ShopGUIPlus, kits, crates o sistemas de economía) para consultar, aplicar, remover y generar ítems con encantamientos personalizados.

---

## 📦 1. Dependencia en tu Proyecto (Gradle / Maven)

Si estás desarrollando otro plugin en el mismo servidor o entorno:

### Gradle (Kotlin DSL)
```kotlin
dependencies {
    compileOnly(files("libs/ZenEnchants-1.0.0.jar"))
}
```

### Maven (`pom.xml`)
```xml
<dependency>
    <groupId>com.cuac_xd.zenenchants</groupId>
    <artifactId>ZenEnchants</artifactId>
    <version>1.0.0</version>
    <scope>provided</scope>
</dependency>
```

Asegúrate de agregar `ZenEnchants` a la lista de `depend` o `softdepend` de tu `plugin.yml`:
```yaml
softdepend: [ZenEnchants]
```

---

## ⚡ 2. Punto de Entrada: `ZenEnchantsAPI`

La clase principal de interacción es [`com.cuac_xd.zenenchants.api.ZenEnchantsAPI`](../src/main/java/com/cuac_xd/zenenchants/api/ZenEnchantsAPI.java). Sus métodos de catálogo se pueden consultar después de que el plugin termine de cargar. Toda operación que lea o modifique un `ItemStack` debe ejecutarse en el hilo principal del servidor.

```java
import com.cuac_xd.zenenchants.api.ZenEnchantsAPI;
import com.cuac_xd.zenenchants.model.ZenEnchantment;
import com.cuac_xd.zenenchants.model.Rarity;
import org.bukkit.inventory.ItemStack;
import org.bukkit.Material;
```

## 🛠️ 3. Ejemplos Prácticos de Integración

### 3.1 Aplicar un Encantamiento Custom a un Ítem
Aplica un encantamiento custom actualizando automáticamente los tags PDC (PersistentDataContainer) y el Lore visual del ítem con colores MiniMessage:

```java
ItemStack espada = new ItemStack(Material.NETHERITE_SWORD);

// Aplicar directamente por ID y Nivel
boolean success = ZenEnchantsAPI.applyEnchantment(espada, "lifesteal", 3);
if (success) {
    player.sendMessage("¡Encantamiento aplicado con éxito!");
}

// O buscando el objeto ZenEnchantment primero:
Optional<ZenEnchantment> lifesteal = ZenEnchantsAPI.getEnchantment("lifesteal");
lifesteal.ifPresent(enchant -> {
    ZenEnchantsAPI.applyEnchantment(espada, enchant, 5);
});
```

---

### 3.2 Leer Encantamientos Custom de un Ítem
Obtén un mapa de todos los encantamientos custom presentes en el ítem junto con sus respectivos niveles:

```java
ItemStack item = player.getInventory().getItemInMainHand();

// Obtener todos los encantamientos custom en el ítem
Map<String, Integer> enchants = ZenEnchantsAPI.getCustomEnchantments(item);

for (Map.Entry<String, Integer> entry : enchants.entrySet()) {
    String id = entry.getKey();
    int level = entry.getValue();
    player.sendMessage("Encantamiento: " + id + " | Nivel: " + level);
}

// Comprobar si tiene uno específico
if (ZenEnchantsAPI.hasCustomEnchantment(item, "telepathy")) {
    int level = ZenEnchantsAPI.getEnchantmentLevel(item, "telepathy");
    player.sendMessage("Este pico tiene Telepathy nivel " + level);
}
```

---

### 3.3 Remover un Encantamiento Custom
Remueve un encantamiento por su identificador y reconstruye el lore del ítem de forma limpia:

```java
ItemStack item = player.getInventory().getItemInMainHand();

if (ZenEnchantsAPI.hasCustomEnchantment(item, "bleed")) {
    ZenEnchantsAPI.removeEnchantment(item, "bleed");
    player.sendMessage("Se ha purgado el encantamiento Bleed de tu arma.");
}
```

---

### 3.4 Crear Libros de Encantamientos con Tasas de Éxito / Destrucción
Genera libros encantados idénticos a los del plugin para recompensas de Crates, Bosses o Tiendas:

```java
Optional<ZenEnchantment> opt = ZenEnchantsAPI.getEnchantment("critical_strike");

if (opt.isPresent()) {
    // Parámetros: encantamiento, nivel, % éxito, % destrucción
    ItemStack libro = ZenEnchantsAPI.createEnchantedBook(opt.get(), 3, 85, 10);
    player.getInventory().addItem(libro);
}
```

---

### 3.5 Crear Libros Misteriosos (Mystery Books)
Genera libros misteriosos que los jugadores pueden abrir con clic derecho:

```java
// Rarezas disponibles: "common", "rare", "legendary", "special"
ItemStack mysteryBook = ZenEnchantsAPI.createMysteryBook("legendary");
player.getInventory().addItem(mysteryBook);
```

---

### 3.6 Crear y Comprobar Polvo Mágico (Magic Dust)
Genera polvos mágicos de éxito para recompensas o plugins de crafteo/tiendas:

```java
// Crear polvo mágico que añade +15% de éxito
ItemStack polvo = ZenEnchantsAPI.createMagicDust(15);
player.getInventory().addItem(polvo);

// Comprobar si un ítem es polvo mágico y obtener su porcentaje
if (ZenEnchantsAPI.isMagicDust(item)) {
    int incremento = ZenEnchantsAPI.getDustRate(item);
    player.sendMessage("Este polvo incrementa el éxito en: +" + incremento + "%");
}
```

---

### 3.7 Consultar Catálogo Completo y Rarezas
Útil para plugins de menús, subastas o wikis internas:

```java
// Lista de todos los encantamientos registrados en el servidor
List<ZenEnchantment> all = ZenEnchantsAPI.getAllEnchantments();
player.sendMessage("Total de encantamientos disponibles: " + all.size());

// Información de una rareza
Optional<Rarity> rareza = ZenEnchantsAPI.getRarity("legendary");
rareza.ifPresent(r -> {
    player.sendMessage("Rareza: " + r.displayNameRaw() + " | Color: " + r.colorTag());
});
```

## 📋 Resumen de Métodos de `ZenEnchantsAPI`

| Método | Retorno | Descripción |
| :--- | :--- | :--- |
| `getEnchantment(String id)` | `Optional<ZenEnchantment>` | Busca un encantamiento por ID. |
| `getAllEnchantments()` | `List<ZenEnchantment>` | Devuelve todos los encantamientos registrados. |
| `getRarity(String id)` | `Optional<Rarity>` | Obtiene los datos de una rareza. |
| `getCustomEnchantments(ItemStack item)` | `Map<String, Integer>` | Devuelve todos los encantamientos custom del ítem. |
| `hasCustomEnchantment(ItemStack item, String id)` | `boolean` | Verifica si el ítem tiene el encantamiento. |
| `getEnchantmentLevel(ItemStack item, String id)` | `int` | Devuelve el nivel del encantamiento en el ítem (0 si no está). |
| `applyEnchantment(ItemStack item, String id, int level)` | `boolean` | Aplica un encantamiento por ID actualizando NBT y Lore. |
| `applyEnchantment(ItemStack item, ZenEnchantment e, int level)` | `void` | Aplica un objeto encantamiento directamente. |
| `removeEnchantment(ItemStack item, String id)` | `void` | Quita un encantamiento y actualiza el Lore. |
| `createEnchantedBook(ZenEnchantment e, int lvl, int succ, int dest)` | `ItemStack` | Crea un libro con tasas de éxito/destrucción. |
| `createMysteryBook(String rarityId)` | `ItemStack` | Crea un libro misterioso abrible con clic derecho. |
| `createMagicDust(int rate)` | `ItemStack` | Crea un ítem de Polvo Mágico con un porcentaje de incremento. |
| `isCustomBook(ItemStack item)` | `boolean` | Indica si el ítem es un libro de encantamiento custom. |
| `isMysteryBook(ItemStack item)` | `boolean` | Indica si el ítem es un libro misterioso sin abrir. |
| `isMagicDust(ItemStack item)` | `boolean` | Indica si el ítem es Polvo Mágico de éxito. |
| `getDustRate(ItemStack item)` | `int` | Devuelve el porcentaje de éxito que otorga el Polvo Mágico. |
