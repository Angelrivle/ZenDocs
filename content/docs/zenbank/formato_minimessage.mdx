# Formato de Texto y MiniMessage

---

ZenBank cuenta con un motor híbrido que interpreta tanto el estándar moderno de Paper como códigos legados:

1. **MiniMessage (Recomendado)**:
   - Degradados / Gradients: `<gradient:#00d2ff:#3a7bd5>Texto en degradado</gradient>`
   - Colores Hexadecimales: `<#00ff88>Texto Verde Neón</#00ff88>`
   - Estilos: `<bold>`, `<italic>`, `<underlined>`, `<strikethrough>`, `<obfuscated>`
   - Colores con nombre: `<gold>`, `<green>`, `<aqua>`, `<red>`, `<gray>`, `<white>`
2. **Formato Legado**:
   - Códigos clásicos con ampersand: `&a`, `&b`, `&e`, `&l`
   - Hexadecimal legado: `&#FF5555Texto Rojo`
